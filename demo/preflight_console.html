          What happens on CortexOne

          This page is step one. The agent runs all four.

          Static checks find what a prompt is missing. Only behaviour shows whether it holds up under pressure. So on CortexOne, PreFlight sends the agent's prompt to an isolated sub-agent, attacks it, and judges the replies with quoted evidence. A deterministic code step then turns those judgements into the verdict.

          40% · code · this page

          Lint

          10 weighted checks, 9 secret detectors, PII with Luhn validation, auditor-tampering scan, risk surface. Leaked secrets ground the agent before any model sees it.

          Red-team

          Judge

          Each reply is marked held, partial or broke, quoting what the agent said. Critical attacks count double. Any critical break fails the agent.
